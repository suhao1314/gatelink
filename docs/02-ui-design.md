# GateLink 活码台 — UI 设计方案

> 版本：v1.0 ｜ 日期：2026-10-27
> 设计基调：简洁、克制、充足留白、层级清晰、交互反馈一致

---

## 一、设计原则

| 原则 | 具体做法 |
|---|---|
| 内容优先 | 界面退到内容后面。大面积白与浅灰，装饰元素只在必要处出现 |
| 层级靠对比而非边框 | 用字号、字重、颜色深浅区分主次，少用描边和分割线 |
| 一致的反馈 | 所有可点元素都有按下态（透明度 0.6）；所有异步操作都有 loading；所有错误都有可理解的中文提示 |
| 一屏一个主任务 | 每个页面只有一个主要行动按钮（主色），其余降级为次级或文字按钮 |
| 少即是多 | 颜色总数控制在 6 个以内，字体只 3 档字重，圆角只 3 种尺寸 |

## 二、配色

### 主色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 / 交互蓝 | `#007AFF` | 仅在「主要按钮」「选中态」「强调数字」使用 |
| 主色按下态 | `#0058B0` | 按钮按下 |
| 背景灰 | `#F5F5F7` | 页面底色 |
| 卡片白 | `#FFFFFF` | 卡片、弹层 |
| 分组灰 | `#FAFAFA` | 次级容器、输入框底 |

### 文字

| 层级 | 色值 | 场景 |
|---|---|---|
| 一级 | `#1D1D1F` | 标题、重要数值 |
| 二级 | `#3A3A3C` | 正文 |
| 三级 | `#6E6E73` | 辅助说明、副标题 |
| 四级 | `#8E8E93` | 占位符、禁用态 |

### 功能色

| 用途 | 色值 |
|---|---|
| 成功 / 启用 | `#34C759` |
| 提醒 / 即将过期 | `#FF9F0A` |
| 危险 / 删除 | `#FF3B30` |
| 分隔线 | `#E5E5EA` |

**用色纪律**：主色在一屏出现不超过 2 次。不用渐变、不用彩色背景块、不用彩色文字强调（除功能色）。

## 三、字体

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text",
             "PingFang SC", "Helvetica Neue", Helvetica, sans-serif;
```

| 代号 | 字号 | 字重 | rpx | 场景 |
|---|---|---|---|---|
| Display | 28pt | 600 | 56rpx | 页面主数值（如访问总量） |
| Title1 | 22pt | 600 | 44rpx | 页面大标题 |
| Title2 | 17pt | 600 | 34rpx | 卡片标题、导航栏标题 |
| Body | 15pt | 400 | 30rpx | 正文 |
| Subhead | 15pt | 600 | 30rpx | 表单 label |
| Footnote | 13pt | 400 | 26rpx | 辅助说明 |
| Caption | 12pt | 400 | 24rpx | 时间戳、角标 |

行高：正文 1.5，标题 1.3，数值类 1.1。
不加载任何网络字体，全部走系统字体，省流量、省首屏时间。

## 四、间距（8pt 网格）

设计基准 375pt 宽，1px = 2rpx。

| 代号 | pt | rpx | 场景 |
|---|---|---|---|
| xs | 4 | 8rpx | 图标与文字间距 |
| sm | 8 | 16rpx | 紧凑元素间距 |
| md | 12 | 24rpx | 卡片内部元素 |
| lg | 16 | 32rpx | **页面左右边距**、卡片间距 |
| xl | 24 | 48rpx | 区块间距 |
| xxl | 32 | 64rpx | 页面级留白 |

**页面左右边距统一 32rpx**，所有区块对齐同一条基准线。

## 五、圆角与阴影

| 元素 | 圆角 |
|---|---|
| 卡片 / 弹层 | 24rpx (12pt) |
| 按钮 / 输入框 | 16rpx (8pt) |
| 标签 / 小徽章 | 8rpx (4pt) |
| 二维码容器 | 24rpx |

阴影：极克制，仅浮层使用。

```css
box-shadow: 0 8rpx 32rpx rgba(0, 0, 0, 0.08);
```

卡片**不加阴影**，用背景色差与页面底色区分，性能更好。

## 六、组件规范

### C1 导航栏

- 高度：状态栏 + 88rpx
- 标题：居中，34rpx，600
- 返回：左侧 44×44pt 点击区，自绘 chevron 图标
- 落地页**动态显示商家自定义标题**

### C2 卡片

```
背景 #FFFFFF，圆角 24rpx，内边距 32rpx，外边距左右 32rpx、上下 16rpx
```

### C3 列表行

```
高度 ≥ 104rpx
左：图标 40×40rpx + 24rpx 间距 + 标题（30rpx）
右：值（26rpx，三级色）+ chevron
底部分隔线：左边距 32rpx 起，1rpx #E5E5EA
```

### C4 按钮

| 类型 | 样式 |
|---|---|
| Primary | 背景 #007AFF，文字白，圆角 16rpx，高 96rpx |
| Secondary | 背景透明，1rpx #007AFF 描边，文字 #007AFF |
| Tertiary | 纯文字 #007AFF，无背景 |
| Destructive | 纯文字 #FF3B30 |
| Disabled | 背景 #E5E5EA，文字 #8E8E93 |

按钮宽度：通栏时左右留 32rpx；半宽时中间间距 24rpx。

### C5 分段控件（Segmented）

```
容器：背景 #F5F5F7，圆角 16rpx，内边距 4rpx
选中：白底 + 微阴影 + 文字 #1D1D1F
未选中：文字 #6E6E73
```

### C6 输入框

```
高度 96rpx，背景 #FAFAFA，圆角 16rpx，内边距左右 24rpx
聚焦：1rpx #007AFF 描边
占位符：#8E8E93
字数统计：右下角 24rpx 三级色
```

### C7 空状态

```
居中，上方自绘插画 160×160rpx（线性、无填充色）
主文案 30rpx #3A3A3C
副文案 26rpx #8E8E93
行动按钮 Tertiary
```

### C8 骨架屏

```
背景 #EEEEEE，圆角同目标元素，透明度 0.6 → 1 呼吸动画
```

### C9 统计卡

```
数值：56rpx，600，#1D1D1F
标签：24rpx，#6E6E73
同比：24rpx，涨 #34C759 / 跌 #FF3B30（本项目口径为访问量，非金融涨跌，故仅作趋势标识）
```

### C10 二维码容器

```
白底，圆角 24rpx，内部留白 48rpx
二维码占容器宽度 78%
下方 32rpx 处一行提示语，26rpx，#6E6E73
```

### C11 图表

不引入图表库，用**纯 view + 宽度百分比**绘制柱状图与折线，零依赖、零请求、渲染快。

## 七、图标规范

- 全部**自生产**（Python PIL 绘制），不使用 emoji，不使用第三方字体图标库
- 风格：单色线性，线宽 2pt，端点圆角，无填充
- 尺寸：输出 81×81px（3x），实际显示 27×27pt
- tabBar 图标：正常态 `#8E8E93`，选中态 `#007AFF`
- 全部单色，用 CSS `opacity` 表达层级，不再做第二套图

**图标清单**：home、chart、user、plus、chevron-right、chevron-left、qr、edit、delete、pause、play、share、download、copy、close、check、warning、empty-box、camera、eye

## 八、关键页面线框说明

### P1 落地页 `landing` — 最高优先级

这是唯一给「访客」看的页面，决定整个产品的转化率。

```
┌────────────────────────────────┐
│  导航栏：商家自定义标题（动态）  │  ← 不用平台默认名
├────────────────────────────────┤
│                                │
│                                │
│          [ 顶部封面图 ]         │  ← 可选，60rpx 圆角
│                                │
│         主标题（44rpx 600）     │
│        副标题（26rpx 三级）      │
│                                │
│    ┌──────────────────────┐    │
│    │                      │    │
│    │    二维码（占 78%）    │    │  ← show-menu-by-longpress
│    │                      │    │
│    └──────────────────────┘    │
│        长按识别，添加咨询        │  ← 商家可编辑
│                                │
│      正文说明段落（可选）       │
│                                │
└────────────────────────────────┘
```

规则：
1. **不出现任何平台名称、会员入口、广告**
2. **不弹任何授权框**，访客无需登录
3. 页面背景用 `#F5F5F7`，内容区一张白卡，视觉集中
4. 首屏不滚动即可看到完整二维码
5. 队列耗尽时显示商家预设兜底码，不显示空白

### P2 活码列表 `index`

```
┌────────────────────────────────┐
│  活码               [+]        │
├────────────────────────────────┤
│  ┌──────────────────────────┐  │
│  │ 雁山拼车群        启用中  │  │
│  │ 3 个子码 · 今日 24 次      │  │
│  │ [查看数据]  [编辑]        │  │
│  └──────────────────────────┘  │
│  ...                           │
└────────────────────────────────┘
```

- 每张卡片显示：名称、状态标签、子码数、今日访问
- 卡片直接给两个高频操作，不到详情页也能点
- 空状态引导「创建第一个活码」

### P3 编辑器 `editor`

分两个区块，**同页切换**，不用二级页面：

```
[ 页面内容 ] [ 二维码队列 ]     ← 分段控件
─────────────────────────────
页面内容：
  导航栏标题   [输入框]
  主标题       [输入框]
  副标题       [输入框]
  正文         [文本域]
  提示语       [输入框]
  主题色       [● ● ● ●]

二维码队列：
  ┌──────────────────────────┐
  │ ≡ 客服小李    配额 50/100 │  │  ← 可拖拽排序
  │ ≡ 客服小王    启用        │  │
  │ ≡ 拼车2群     即将过期    │  │
  └──────────────────────────┘
  [+ 添加二维码]

底部固定：[获取二维码]  [保存]
```

### P4 数据看板 `stats`

```
[ 今日 ] [ 7天 ] [ 30天 ]        ← 分段
─────────────────────────────
  访问总量          独立访客
   1,284              936
   较前日 +18%
─────────────────────────────
  时间趋势
  ▁▃▅▂▇▄▆  （纯 view 柱状图）
─────────────────────────────
  来源分布
  海报A   ████████  42%
  传单    █████     26%
  直接    ███       18%
─────────────────────────────
  子码展示占比
  客服小李 ███████  51%
─────────────────────────────
  [ 生成分享链接 ]
```

所有数据**一个接口返回**，页面不发第二次请求；切换时间范围时本地重算（接口一次拉全区间）。

### P5 分享看板 `share`

与 P4 同构，但：
- 顶部显示「来自 XX 的数据看板」+ 生成时间
- 不显示敏感操作入口
- 无 tabBar，右上角一个「返回」

### P6 我的 `profile`

极简，只有：账号信息、我的活码数、清除缓存、关于、退出登录。**不做会员、不做套餐**。

## 九、交互规范

| 场景 | 反馈 |
|---|---|
| 点击任何可点元素 | `opacity: 0.6`，120ms 恢复 |
| 提交/加载 | 按钮内 spinner，禁用重复点击 |
| 操作成功 | 顶部 Toast，1.5s |
| 操作失败 | Toast 显示具体中文原因，不显示技术报错 |
| 删除 | 二次确认弹窗（Apple 风格居中对话框） |
| 列表为空 | 占位插画 + 一句引导 + 行动按钮 |
| 网络异常 | 全屏可刷新状态，不白屏 |

**Toast 文案示例**（全部中文，无技术词）：
- 「已保存」
- 「二维码已保存到相册」
- 「链接已复制」
- 「网络不太顺，稍后再试」
- 「这张码已经下线了」

## 十、适配

- 机型范围：iPhone SE (320pt) 至 iPhone 15 Pro Max (430pt)
- 全部布局用 flex + rpx，不写死高度
- 底部操作栏加 `env(safe-area-inset-bottom)` 适配
- 输入框聚焦时页面不上推过快（cursor-spacing 设 100rpx）
