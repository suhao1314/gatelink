### 关键验证点

| 验证项 | 实际结果 |
|---|---|
| 顺序轮询 | 6 次访问序列 A,B,A,B,A,B，两个子码均匀轮换 |
| 随机分配 | 8 次访问出现多个不同子码 |
| 配额分配 | 子码配额 1 时只命中 1 次，之后自动切到下一个 |
| 过期跳过 | 过期子码在 3 次访问中一次都没被选中 |
| 兜底生效 | 队列耗尽时返回兜底码并标记 fallbackUsed |
| 独立访客去重 | 同一访客重复访问，独立访客数不增长 |
| 二维码缓存 | 同参数二次请求返回完全相同的字节 |
| 权限隔离 | 第二个用户读取/修改/删除他人活码均返回 403 |
| 非图片上传 | 文本伪装成图片时被拒绝，返回 BAD_TYPE |
| XSS 防护 | H5 页面输出不含任何 script 标签 |
| 逾越尺寸夹紧 | size=99999 被夹到上限且正常返回 |
